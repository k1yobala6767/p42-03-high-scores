## Условие

Продолжение Задания 7. В проекте готовые файлы: Student.cs (класс студента) и SampleData.cs (SampleData.Group() создаёт группу из 8 студентов с оценками). Их менять нельзя.

Студент с высоким баллом: у него есть хотя бы одна оценка (HasScores) и средний балл не ниже порога (Average >= minAverage). Студент без оценок в список не попадает никогда.

Напишите в Program.cs два метода:
1) CountHigh(group, minAverage) возвращает, сколько в группе студентов с высоким баллом.
2) FindHigh(group, minAverage) возвращает новый массив только из этих студентов, в том же порядке, что в группе. Длина массива равна числу найденных: сначала посчитайте (можно через CountHigh), потом заполняйте. Новые объекты Student не создавайте, кладите в массив ссылки из group.

Работаем только с массивами: List и LINQ не используйте.

**Примеры**

```
Группа SampleData.Group(), средний балл:
Сериков Дамир 72,3 · Ахметова Айгерим 91,7 · Ким Анна 95 · Петровых Александр 61 · Бекова Мадина 84,3 · Ли Виктор (нет оценок) · Жумабаев Нурлан 90 · Денисова Ольга 85

CountHigh(group, 85) → 4
FindHigh(group, 85) → Ахметова Айгерим, Ким Анна, Жумабаев Нурлан, Денисова Ольга
Пояснение: у Денисовой Ольги ровно 85, она подходит (>=)

FindHigh(group, 95) → Ким Анна

FindHigh(group, 0) → все, кроме Ли Виктора
Пояснение: у Ли Виктора нет оценок, его средний 0, но он не попадает в список
```

## Как выполнить

1. Один человек из команды нажимает **Fork** (вверху справа) и добавляет напарника: Settings → Collaborators → Add people.
2. Оба клонируют форк и открывают его в VS Code:
   ```
   git clone https://github.com/<ваш-ник>/p42-03-high-scores
   cd p42-03-high-scores
   code .
   ```
3. Впишите в таблицу «Команда» выше свои ФИО и ники GitHub.
4. В `Program.cs` напишите решение внутри методов `CountHigh` и `FindHigh` (вместо строк `// TODO`). Не меняйте `Student.cs`, `SampleData.cs` и методы `Main`, `Check`, `Names`.
5. Запустите:
   ```
   dotnet run
   ```
   Все проверки должны показать `OK`.
6. Сохраните работу в GitHub (коммитят оба участника):
   ```
   git add .
   git commit -m "Решение"
   git push
   ```
